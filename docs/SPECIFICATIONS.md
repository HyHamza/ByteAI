# SeniorEngineer Functional & Technical Specifications

## 1. Feature Specifications

### 1.1 Workspace & Project Management
- **Project Folder Picker:** Select any directory on the local machine (e.g. `e:\CODE\MyProject`).
- **Workspace State Persistence:** Store project-specific settings, active branches, `.ai/` directory contents, and chat histories in a local SQLite database (`~/.seniorengineer/data.db`).
- **Multi-Tab Sessions:** Support multiple concurrent chat sessions per project.

### 1.2 Model & Endpoint Gateway
- **Custom Endpoint URL:** Input any OpenAI-compatible base URL (e.g. `http://localhost:11434/v1`, FreeLLM proxy endpoints, OpenRouter, or Google Gemini API).
- **API Key Management:** Encrypted local vault storage for keys (`JULES_API_KEY`, `OPENAI_API_KEY`, custom keys).
- **Model Selector:**
  - Auto-fetch available models via `GET /v1/models`.
  - Manual model override text input.
  - **"Auto Router" Option:** Dynamically switches between lightweight models for fast tool routing and deep reasoning models for planning and code review.

### 1.3 Autonomous Agent Loop (No Unnecessary Questions)
- **Continuous Execution Engine:** Operates on goals rather than single turns.
- **Autonomous Continuation:** When an objective requires multiple steps (e.g., read file $\rightarrow$ analyze $\rightarrow$ run build $\rightarrow$ fix errors), the loop continues automatically without asking the user for confirmation after every step.
- **Circuit Breakers:** Safeguard against infinite loops:
  - Max autonomous turns per user instruction (configurable, default: 50).
  - Repetitive tool detection (stops if the exact same tool call and arguments are repeated 3 times with identical failures).
  - Explicit confirmation requested only for destructive operations (e.g., `git reset --hard`, `rm -rf`).

## 2. Tool Specifications

### 2.1 Standard Mode Tools (Generic Antigravity Engine)

| Tool Name | Parameters | Purpose |
|---|---|---|
| `read_file` | `path: string`, `start_line?: number`, `end_line?: number` | Read file contents with line slicing. |
| `write_file` | `path: string`, `content: string`, `overwrite: boolean` | Create or overwrite files. |
| `edit_file_content` | `path: string`, `target_content: string`, `replacement_content: string` | Precise surgical code replacement. |
| `run_terminal_command` | `command: string`, `timeout_ms?: number` | Run shell command (PowerShell / Bash) with live stdout/stderr. |
| `codebase_search` | `query: string`, `path?: string`, `regex?: boolean` | Fast Ripgrep-powered code and text search. |
| `list_directory` | `path?: string`, `recursive?: boolean` | List directories and file trees. |

### 2.2 Jules Mode Tools (Senior Lead Orchestrator)

| Tool Name | Parameters | Purpose |
|---|---|---|
| `jules_create_task` | `prompt: string`, `repo?: string`, `branch?: string`, `title?: string` | Formulates a high-level technical spec and creates a new Jules session. |
| `jules_reply_question` | `session_id: string`, `response: string` | Answers Jules' architectural or disambiguation questions. |
| `jules_inspect_diff` | `session_id: string` | Fetches the full git patch and changeset generated by Jules. |
| `jules_verify_changes` | `session_id: string`, `test_command?: string` | Checks out the Jules PR branch locally and runs verification tests. |
| `jules_approve_and_merge` | `session_id: string`, `push_to_remote?: boolean` | Merges the Jules PR branch into main/target and triggers push. |
| `jules_start_domain_loop` | `domain: string`, `max_cycles?: number` | Spawns the autonomous audit loop (`jules_loop.js`) for continuous domain sweeps. |

> **Crucial Rule:** In Jules Mode, `write_file` and `edit_file_content` are excluded from the model's function list. Grunt-work implementation is strictly delegated to Jules.

## 3. IPC Channel Contracts

Communication between React (Renderer) and Electron (Main) uses strongly-typed IPC:

```typescript
// Electron API exposed via contextBridge
export interface ElectronAPI {
  // LLM & Chat
  sendMessage: (sessionId: string, message: string, mode: 'standard' | 'jules') => Promise<void>;
  cancelExecution: (sessionId: string) => Promise<void>;
  onStreamToken: (callback: (data: StreamTokenPayload) => void) => () => void;
  onToolCallUpdate: (callback: (data: ToolCallPayload) => void) => () => void;

  // Workspace
  selectDirectory: () => Promise<string | null>;
  getProjectTree: (dirPath: string) => Promise<FileNode[]>;

  // Configuration
  getSettings: () => Promise<AppSettings>;
  saveSettings: (settings: Partial<AppSettings>) => Promise<boolean>;

  // Jules Mission Control
  getJulesSessions: () => Promise<JulesSessionSummary[]>;
  getJulesSessionDetail: (sessionId: string) => Promise<JulesSessionDetail>;
  onJulesStatusUpdate: (callback: (update: JulesUpdatePayload) => void) => () => void;
  triggerJulesMerge: (sessionId: string) => Promise<MergeResult>;
}
```
